# 역사·지리·자원 보강 출처 검증

확인일: 2026-10-18. 대상: `src/central-asia-history.js`, `src/central-asia-geography-climate.js`, `src/central-asia-power-datacenters.js`. 본문은 별도 통합 담당자가 수정한다. 아래는 이 감사에서 실제로 열거나 검색된 원자료의 주장 대응표이며, 전체 문장 하나하나의 독립 검증을 완료했다는 뜻은 아니다. 발행일과 검색엔진의 수집일은 구분했다.

## 바로 반영할 수정

1. 자원 출처의 `https://www.worldbank.org/en/region/eca/brief/water-in-central-asia`는 직접 HTTP 요청에서 **404**. 아래 2023 관개·배수 보고서와 Kambarata FAQ로 교체한다.
2. 지리 출처에 톈산 지각운동 연구와 사과 유전체 연구를 추가한다. UNESCO만으로 지질·유전학의 상세 기전을 모두 입증한 것으로 표시하지 않는다.
3. 역사 출처에 카자흐 칸국 연표, 알마티 수도 이전, 비슈케크 연구를 추가한다. 현재 원고의 **1929년 자치공화국 / 1936년 연방공화국** 구분은 정확하다.
4. 비슈케크의 직교 가로망은 제정 러시아 때 도입됐다. 역사 마지막 장의 ‘비슈케크의 계획 가로망 … 이 시기의 흔적’은 소련이 처음 만들었다는 인상을 피하도록 **‘제정기 가로망 위에 확장된 소련기 비슈케크’** 등으로 수정 권고.
5. 아프라시압은 건물의 궁전 여부부터 논쟁이 있다. 현재 원고의 ‘흔히 궁전의 사절의 방으로 불림 / 건물 성격에 논의’와 ‘고구려 사절 실제 방문 미확정’을 유지한다.
