## C. 역사 보완과 기존 상세 정보

- 소그디아·박트리아, 농업 잉여와 오아시스, 친족·신용·언어를 이용한 소그드 교역, 초원과 도시의 상호의존을 연결했다. 실크로드는 변하는 교역망으로 설명했다.
- 아프라시압을 별도5문단으로 다뤘다. 1965년 발견·7세기 벽화·서벽의 복식과 명문을 관찰 사실로, 고구려 사절의 신원·실제 방문·모본/상징 해석을 학술 논의로 구분했다. 현지 박물관·KCI한국논문·Iranica를 교차 확인했다.
- 튀르크계 정치세력, 아랍 진출, 사만·카라한과 언어·신앙의 서로 다른 변화 속도를 서술했다. 샤시마콤은 국경을 넘는 도시 문화유산으로 연결했다.
- 몽골 정복의 피해와 교역 재편, 차가타이 울루스, 티무르의 정통성·장인 동원, 울루그베크의 집단적 천문 관측을 연결했다.
- 레기스탄의15·17세기 차이, 포이칼랸의12·16세기 차이, 구르에미르·비비하눔의 정치적 목적을 명시했다. 부하라·사마르칸트 상세의 유적별 고유 설명은 남겼다.
- 카자흐 칸국·러시아의 초원 지배, 톈산 키르기스의 복합적 형성과 코칸드·1916년 우르쿤을 추가했다. 민족·국경을 고대에 소급하지 않았다.
- 러시아 제국 철도·면화와 식민지적 구조, 소련 교육·산업화와 강제집단화·기근·숙청·강제이주, 국경 획정·1991년·국가 정체성을 구분했다.

6개 도시와 건축 상세의 장 순서·이미지 삽입 위치를 보존했다. [역사·지리·자원 주장별 근거](audit/source-check.md)는 중요한 논쟁·오류 위험을 다룬 기록이며 모든 기존 역사 문장을 새 사료로 독립 검증했다는 뜻은 아니다.

## J. 인계 후 재확인과 PWA 후속 수정

2026-10-18 UTC 재개 시 GitHub API를 다시 조회했다. PR #1은 open·미병합·mergeable=true, head는 `d4d24b80a2b5c49e471bffee149788dba7e9a079`, main은 `e3423e7246c2118cc641b35220cba04359459ab8`였다. head의 검증 [39140580438](https://github.com/JinhaPark/codex/actions/runs/39140580438)과 main의 Pages 배포 [39110684827](https://github.com/JinhaPark/codex/actions/runs/39110684827)는 completed/success였다. 실제 사이트 HTML은 HTTP 200, SHA256 `2dee33480f66ee510090509bebed0eb17a009d09da2d4e97322419231acfe2d3` 및 기존 main 자산 이름으로 확인했다. 이는 재개 시점의 관측이며 이후 커밋 상태를 대신하지 않는다.

감사·출처·교육·이미지·브라우저 기록과 371문단 원장의 조치/목적지를 확인했다. 원장은 유지115·수정110·통합84·삭제62이며 조치·사유·근거 파일 누락은 없었다. 원고·통계·이미지에는 이번에 변경을 가하지 않았다.

추가로 발견한 실제 오류는 서비스 워커의 캐시 범위였다. 기존 activate는 같은 origin의 모든 다른 캐시를 삭제했고, fetch는 origin 전체 캐시에서 응답을 찾았다. GitHub Pages의 다른 프로젝트가 같은 도메인을 사용하는 경우 영향을 줄 수 있다. `tests/service-worker.test.js`에서 수정 전 타 사이트 캐시 삭제와 타 캐시 응답 반환을 재현했다. `public/sw.js`를 다음처럼 수정했다.

- 오래된 `ca26-pages-` 캐시만 정리하고 현재 가이드 캐시에서만 응답을 조회한다.
- 정상 응답 저장을 `event.waitUntil`로 추적해 응답 후 워커 종료 전에 캐시 쓰기를 완료할 기회를 확보한다. 저장 실패가 온라인 응답을 막지 않도록 처리한다.
- 다른 origin·경로와 GET 외 요청은 계속 가로채지 않는다.

후속 검증: `npm test` 10/10, `npm run build` 통과. Chromium 153에서 375·390·430px 전체 회귀를 다시 실행해 통과했다(`browser.json` 2026-10-18T15:42:53.889Z). 기존 23점·63개 WebP, 지도40개, 경제표12수치, 준비물·음성 fallback·환율 fixture·오프라인 확인에 더해, v5→v6 통제 업데이트에서 타 사이트 캐시 내용이 보존되는 것을 실제 브라우저에서 확인했다. 375px 경제·교육 스크린샷도 육안 확인했다. JS/CSS 번들명은 기존 작업 브랜치 빌드와 동일하며 변경된 배포 자산은 `sw.js`다.
