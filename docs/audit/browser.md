검증일: 2026-10-18. `npm run build`로 생성한 로컬 프로덕션 빌드를 Chromium 153.0.8010.0에서 검사했습니다. 실행 코드와 기계 판독 결과는 `scripts/verify-browser.cjs`, `docs/audit/browser.json`에 있습니다. Playwright와 별도 Chromium 실행 파일을 사용하는 선택적 통합 검사이며 프로덕션 의존성은 추가하지 않았습니다.

## 육안 검사에서 발견해 수정한 사항

경제표의 모바일 `caption`이 좁게 줄어 제목이 세로로 끊기던 현상을 발견했습니다. 모바일에서 제목을 전체 너비의 블록으로 표시하도록 수정하고, 제목 폭 검사도 추가했습니다.

교육표를 모바일 카드로 바꾼 뒤 숨겨진 열 제목에만 남아 있던 등록금 단위를 발견했습니다. 각 등록금 셀에 `만 원/년`을 직접 표시하도록 수정하고, 브라우저 검사에 단위 보존 조건을 추가했습니다. 375px 경제·교육 및 430px 경제 화면을 실제 이미지로 확인했습니다. 숫자·단위와 조건 설명이 읽히며 화면 밖으로 잘리지 않습니다.

스크린샷 6개는 실행 시 저장소 밖 `qa-integration/`에 생성합니다. 브라우저 내 한국어 글꼴 확인을 위해 로컬 QA용 Noto Sans KR을 주입했으며 사이트에 의존성을 추가하지 않았습니다.

## 검증 범위의 한계

- 실제 iPhone Safari·실물 기기 검사가 아닌 Chromium 모바일 뷰포트 검사입니다.
- 환율 API는 결정적인 테스트 응답으로 계산과 UI를 검사했습니다. 외부 환율 서비스의 현재 가용성을 통과로 간주하지 않습니다.
- 지도 링크의 URL 구조를 확인했으며 외부 지도 검색 결과나 현지 길찾기 정확성을 검증한 것은 아닙니다.
- PWA 업데이트는 현재 앱에 이전 캐시명을 적용한 통제 조건입니다. 실제 과거 배포 번들의 모든 버전에서의 마이그레이션을 검증했다고 주장하지 않습니다.
- 오프라인 검증은 이미 방문해 캐시된 앱과 이미지에 한정됩니다. 방문하지 않은 모든 이미지·외부 출처·지도·최신 환율의 오프라인 제공을 보장하지 않습니다.
- 새 PR은 아직 병합·배포되지 않았습니다. 이 결과는 로컬 프로덕션 빌드이며 GitHub Pages의 새 버전 배포 성공을 뜻하지 않습니다.
- `browser.json`의 섹션 어절 수는 화면의 핵심 본문만 추출한 회귀 검사입니다. 전체 원고 감축률은 별도의 동일 기준 편집 측정 보고서를 따릅니다.
