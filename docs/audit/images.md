## 실제 수행한 검증

- 23점 전체를 연락시트로 육안 확인하고 식판 그림은 800px 원본 크기로 추가 확인했습니다. 건축 전경·호수·풍경의 수채화와 문양·필사본·음식·제품의 색연필화가 기존 혼합 화풍과 일치합니다. 기존 승인된 조각 정원 색연필화는 유지했습니다.
- 63개 WebP를 Pillow로 열어 실제 픽셀 크기와 파일 바이트 수를 기록값과 대조했습니다. 불일치 0개입니다.
- 실제 WebP RIFF 청크와 Pillow 메타데이터를 검사했습니다. EXIF·GPS·XMP 청크가 없고, 공개 일러스트 디렉터리에 원본 HEIC/JPEG가 없습니다.
- 63개 SHA-256 해시가 모두 달라 바이트 단위 중복 파일이 없습니다. 같은 작품의 반응형 크기 외에 작품 ID·배치 키·캡션도 중복되지 않습니다.
- 전체 자산 11,336,530바이트(10.81MiB); 각 작품의 표준본 합계 4,343,100바이트(4.14MiB). 실제 전송량은 화면에서 필요한 반응형 파일과 방문 탭에 따라 달라집니다.
- 표준본 22점은 250KB 이하입니다. 복잡한 레기스탄 천장은 문양 보존을 위해 기존 예외 316,698바이트를 유지했습니다. 큰 파생본 최대 484,398바이트이며 원본보다 확대하지 않습니다.
- 원본 폭이 370px 또는 800px인 4점은 1200px 파일을 만들지 않았습니다. 각 파생본의 비율은 픽셀 반올림 오차 범위 내에 보존됩니다.
- 렌더러의 `srcset`, `sizes`, `width`·`height`, `loading="lazy"`, `decoding="async"`를 유지했습니다. 실제 모바일 렌더링과 전체 배치 도달 여부는 통합 QA 보고서를 참조하십시오.
