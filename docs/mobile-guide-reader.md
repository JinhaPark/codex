# 여행 해설 모바일 탐색과 읽기

해설 목록에서 종합 해설·도시/유적·카자흐스탄 심층 중 하나를 고르고, 선택한 글만 화면에 표시합니다. 기존 종합 해설 다섯 편의 순서와 카자흐스탄 심층 세 편의 독립성을 유지합니다. 쇼핑·준비 화면은 PR #20이 병합된 main을 기준으로 보존했습니다.

## 펼침 단위와 콘텐츠 보존

`src/guide-sections.js`의 명시적 구간표로 기존 소제목을 1~4개의 큰 번호 섹션으로 묶습니다. 부하라는 15개 소제목을 4개, 사마르칸트·타슈켄트·비슈케크·촐폰아타·알마티는 각각 3개로 묶습니다. 섹션 안의 세부 소제목·문단·사진은 함께 펼쳐집니다. 섹션끼리는 독립적으로 열 수 있으며 전체 펼치기·전체 접기는 본문의 큰 섹션에만 적용합니다. 출처와 계산 근거는 별도로 접어 둡니다.

원문 데이터는 변경하지 않습니다. 기존 장의 인덱스로 일러스트를 렌더링하므로 편집 위치·캡션·이력 자료를 바꾸지 않습니다. 원고에 장을 추가할 때 구간표도 함께 검토해야 하며, 누락·순서·인덱스 보존을 자동 검사합니다.

## 주소·상태·접근성

- `#guide/core/history`, `#guide/cities/history-almaty/almaty-section-3`처럼 글과 큰 섹션을 직접 연결합니다. GitHub Pages의 경로 재작성 없이 오프라인에서도 이동합니다.
- 기존 `#history-almaty`, `#silk-road-introduction`, `#city-guides`, `#kazakhstan-deep-dives` 등의 주소는 해당 글이나 분류로 연결합니다.
- 목록의 분류·스크롤과 글별 펼침 상태·스크롤은 `central-asia-reader-v1` 키로 이 기기에 저장합니다. 저장소 접근이 차단되어도 읽기와 이동을 계속 사용할 수 있습니다. 기존 체크리스트 키는 보존합니다.
- 목차는 기본 dialog의 모달과 키보드 포커스를 사용합니다. 선택한 큰 섹션을 열고 이동한 뒤 summary에 포커스를 둡니다. Escape로 닫을 수 있습니다.
- 목차 버튼에 현재 큰 섹션 번호를 표시합니다. 상단 도구는 스크롤 중에도 유지되며 목차 이동 여백을 확보합니다. 모든 글에 목차가 있으므로 하단 섹션을 찾기 위해 앞의 긴 본문을 모두 스크롤할 필요가 없습니다.

## 검증

`npm test`, `npm run build`를 실행합니다. 선택적 브라우저 검사는 Playwright 및 Chromium을 준비하고 다음 명령을 실행합니다.

```sh
NODE_PATH=/path/to/node_modules QA_CHROMIUM=/path/to/chromium node scripts/verify-browser.cjs
```

이 검사는 375·390·430px, 10일 일정, 16개 해설, 큰 섹션 조작·목차·뒤로 가기·탭 전환·재진입 상태 복원, 기존 사진·캡션·표·환율 fixture·체크리스트, 방문한 해설 이미지의 오프라인 재진입과 서비스워커 캐시 전환을 확인합니다. 결과와 스크린샷은 저장소 밖 `qa-guide-reader/`에 출력합니다. 선택적으로 인접한 `qa-runtime/`의 Noto Sans KR을 검사 환경에서만 사용합니다.

실제 iPhone Safari와 홈 화면 웹앱의 검증을 대신하지 않습니다. 캐시 전환은 현재 앱과 이전 캐시명을 조합한 fixture이며 과거 배포 파일 자체의 전환 시험이 아닙니다. 방문하지 않은 사진의 오프라인 표시를 보장하지 않습니다. 검색·예상 읽기 시간·별도 이어 읽기 목록은 후속 범위입니다.
