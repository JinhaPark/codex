## 원본 및 메타데이터

- 원본 사진과 미선택 색연필 풍경 시안은 저장소에 포함하지 않습니다.
- 게시용 WebP에는 EXIF·GPS·XMP·ICC 프로필이 없습니다.
- 차량 번호판 문자는 알아볼 수 없도록 그렸습니다.
- IMG_8981(1).jpeg는 IMG_8981.jpeg와 동일하므로 한 점만 사용합니다.
- 일정표 5장, 헤어 제품, 리모컨, QR 안내판은 배치하지 않습니다.
- 필사본 문자와 제품 라벨은 사진을 바탕으로 한 예술적 재현입니다. 문자 판독이나 제품 정보의 근거로 쓰지 않습니다.

## 제작 방식

imagegen으로 각 사진을 직접 참조하여 개별 제작했습니다. 공통 지시: 원본 구도·가로세로 비율·주요 지형과 구조물을 유지하고, 랜드마크를 추가하거나 제거하지 않으며, 은은한 종이 질감과 절제된 자연색을 사용합니다. 수채화는 투명한 번짐, 색연필화는 섬세한 선과 부드러운 음영을 사용합니다. 포이칼랸은 돔·미나레트·중정, 정원은 조각·수목·건물, 타일은 아치·벽면 문양의 위치 보존을 우선했습니다.

## 검증 결과

- npm test: 6건 통과(기존 경제 데이터 4건, 이미지 파일·메타데이터·중복 배치 2건).
- npm run build: 통과. 새 프로젝트 의존성 없음.
- Chromium 153: 320·375·390·430·1024px 화면 폭에서 가로 넘침 없음.
- 12점 실제 디코딩, 36개 경로 HTTP 200 및 WebP 헤더·파일 용량 확인.
- 한국어 alt, 캡션, lazy loading, srcset 및 width/height 예약 확인.
- 일정 10개·여행 해설·환율/회화·준비물 총 13개 상태를 변경 전과 비교: 삽화와 읽기 안내 문구 한 곳을 제외한 본문 텍스트 동일.
- 테스트 중 uncaught JavaScript 오류 0건. 준비물 체크 상태는 새로고침 후 유지.
- 375px에서 수채화·건축·쇼핑 화면을 직접 렌더링하여 시각 점검.
- 오프라인 서비스워커 캐시 버전을 변경하여 새 배포의 파일을 다시 받도록 했습니다. 한 번 열어본 수채화는 네트워크를 끊고 새로고침한 후에도 정상 디코딩됨을 Chromium에서 확인했습니다.
- 실제 iPhone Safari 기기 검증은 수행하지 않았습니다.
