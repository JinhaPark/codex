# Restore the plain green banner

The user rejected the generated map because lake positions, relative city locations, coastlines, boundaries, and routes did not preserve the original geographic information. The map is no longer suitable for publication. This change starts from main `bc55e1b27c07d1758afb2436fb86d0878946eb46` and restores the simple header treatment that preceded the artwork, using `fd1deea793c20cbafaba21673eef64f79ebbc226` as the design reference.

The header now has the original dark green background (`#14313c`), gold accents (`#e6c98c`), trip dates, title, and countries as ordinary HTML. Text wraps naturally on phones. It uses the site's font stack for reliable Korean rendering. The image element, responsive map sources, illustration import, translucent title band, and horizontal title scroller are removed. Other content and the rest of the site's current palette remain unchanged.

The map is removed from the publication manifest and destination coverage list. Its lineage entry and formerly active r5 revision are marked archived, with no active revision or placement. The last-published pointer and all previous source hashes, recipes, revisions, and WebPs are retained. This withdraws the artwork from the interface without deleting its audit history or unrelated images. Historical generation and software validation records do not establish geographic accuracy; the user's rejection and retirement supersede the earlier publication decision.

Cache v38 refreshes the header without changing service-worker behavior. Banner tests now check HTML content, absence of map requests, and archived history. Two lineage fixtures now select an active image rather than assuming the final manifest entry remains published. The browser script verifies the plain background, readable text, responsive layout, and offline header instead of expecting the retired image.

Validation: all 81 tests passed; the production build and diff checks passed. The image audit decoded 51 published illustrations and 137 active variants. Focused Chromium checks passed at 375, 390, 430, 768, 1280, and 1920px, including offline reload with zero map-image requests, a cache upgrade fixture from v37 to v38, and preservation of an unrelated cache. Screenshots were reviewed. Results are in `plain-green-banner-browser.json`. Unrelated guide flows were not rerun; actual iPhone Safari and installed home-screen testing remain outstanding.
