# 교육 검증·편집 기록

조회일: 2026-10-18. 표시 금액은 2026-10-17 키르기스 중앙은행 교차환율로 환산했다. 원자료 금액은 `src/education-data.js`에 보존한다. 환율은 `src/research-data.js`의 공통 값만 사용한다.

## 구현과 범위

- `src/central-asia-education.js`: 다섯 번째 핵심 섹션. 접근성·성취 → 계약제 → 등록금·생활비 → 가계 조달 → 학업 지속 순서. 최초 작성 기준 본문 478어절·2,192자(제목·표·출처 제외).
- `src/education-data.js`: 원자료의 금액, 모집단, 학년도, 발표일, 조회일, 계산식, 확인 한계.
- `src/render-education.js`: 본문과 접이식 등록금·생활비 표 및 출처. 화면에 원화 표시.
- `tests/education.test.js`: 연간 비용의 구성과 환산, 원화 표시, 출처 한계 노출을 검증하는 2개 테스트.

등록금은 전국 평균 월급의 약1.2~2.7개월분이다. 원룸 월세는 같은 임금의 약56~79%이지만 연도와 지역·모집단이 달라 특정 학생 가구의 실제 부담률을 뜻하지 않는다. 독립거주 시나리오는 전국 평균임금을 12개월 받은 세전 총액 약812.5만원과 비슷하거나 더 크다. 이 비교 역시 학생 부모의 실제 소득을 추정하는 계산이 아니며 가구원 수·취업자 수·세금·이전소득을 반영하지 못한다.

시나리오는 출처가 다른 등록금과 생활 항목을 합친 별도 계산이다. 기사에 실린 완전한 생활비 합계를 그대로 복제한 값이 아니다. 보증금·교재·의료·의복·여가·예비비를 제외한다. 원룸과 기숙사 모두 식료품·교통·통신은 같은 절약 가정을 사용한다.

## 출처와 관측 조건

전체 URL·발표일·모집단은 `educationSources`에 기록하고 화면의 출처 접이식 영역에도 표시한다.

- KNU: 2026-06-23 게시. 스캔1~2쪽에서 2026/27, 학부 주간, 학년별 금액을 직접 확인.
- KSMA: 공식 약학 페이지의 2025/26 요율. 게시일은 표시되지 않아 조회일과 구별.
- KRSU: 현재 공식 표 제목은2026/27, 경제학 학사 금액 확인. 적용 입학연도 미기재.
- Kaktus: 실제 발표일은 **2026-06-26**. 공식 통계나 학생 표본조사로 취급하지 않음.
- KSMA 기숙사: 공식 대학 서브도메인에 게시된 요금은 검색 색인에서 확인. 직접 열기는 실패했으며 기준연도도 미표시. 현행 요금으로 확정하지 않음.
- WDI/UIS 성인 문자해득률 API 최신 비어 있지 않은 관측: KAZ2009 99.7300033569336%, UZB2022 100%, KGZ2009 99.2399978637695%. 오래된 관측이라는 한계를 본문에 명시.
- PISA2022: OECD 국가별 노트(2023-12-05 발표), 수학2단계 이상 KAZ50%·UZB19%·OECD69%. KGZ 동년 미참여.
- IMF2025 노동시장 연구: 기술 불일치 설명에 사용. 개인별 학업 중단 인과효과로 확대하지 않음.
